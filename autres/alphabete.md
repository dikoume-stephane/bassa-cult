| ɖ | /ɖ/ | Consonne occlusive rétroflexe sonore. |

## Autres symboles bassa

| Symbole | Usage | Remarque |
| :-- | :-- | :-- |
| ’ | Coupure glottale ou séparation | Utilisé dans certaines transcriptions. |
| ː | Allongement vocalique | Marque une voyelle longue. |
| ˊ | Ton haut | Selon les systèmes de notation tonale. |
| ˋ | Ton bas | Selon les systèmes de notation tonale. |
| ˜ | Nasalisation | Peut apparaître selon les conventions de transcription. |
| . | Séparation syllabique ou morphologique | Selon les choix typographiques. |

## Double articulation

| Groupe | Phonétique | Explication |
| :-- | :-- | :-- |
| gb | /ɡ͡b/ | Consonne produite avec une fermeture simultanée vélaire et bilabiale. |
| kp | /k͡p/ | Consonne produite avec une fermeture simultanée vélaire et bilabiale, sourde. |
| ny | /ɲ/ | Consonne nasale palatale, parfois considérée comme un seul phonème complexe. |
| mb | /mb/ | Nasale + consonne sonore, fréquente dans les langues bantoues. |
| nd | /nd/ | Nasale + occlusive alvéolaire sonore. |
| ng | /ŋg/ ou /ŋ/ | Séquence nasale vélaire selon le mot. |
