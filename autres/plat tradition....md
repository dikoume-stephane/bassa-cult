## 🍽️ Plats Traditionnels Bassa : La Gastronomie Bassa


***

### **L'Okok** (ou Ikok)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Plat festif traditionnel du peuple Bassa (Littoral \& Centre, Cameroun) [^1][^2] |
| **Base principale** | Feuilles d'okok (dokok) finement découpées [^3][^4] |
| **Ingrédients clés** | Noix de palme, arachides écrasées, huile de palme, écrevisses, poisson fumé, viande de bœuf [^3][^5] |
| **Caractéristique** | Ragoût de feuilles vertes cuisiné longuement, texture épaisse et savoureuse [^2][^6] |
| **Accompagnement** | Miondo (bâton de manioc), plantains mûrs bouillis, riz [^3] |
| **Cuisson** | Feuillage bouilli puis cuisiné 2-3 heures avec les arachides [^5][^6] |


***

### **Le Ndolè** (ou Metet)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Plat emblématique du Cameroun, originaire des Bassa [^7][^8] |
| **Base principale** | Feuilles de Vernonia (feuilles de ndolè) [^7][^8] |
| **Ingrédients clés** | Pâte d'arachides fraîches, gingembre, piment, tomate, poisson séché, crevettes, viande [^7][^8] |
| **Caractéristique** | Sauce amère aux feuilles épicées, purée d'arachides onctueuse [^7][^9] |
| **Accompagnement** | Miondo, plantains mûrs, riz [^7] |
| **Cuisson** | Feuilles bouillies 3 fois pour retirer l'amertume, puis cuissons 45-75 min [^7][^8] |
| **Vertus** | Plante aux vertus thérapeutiques reconnues [^8] |


***

### **Le Mbongo'o** (Mbongo Tchobi / Sauce Ébène)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Plat issu de la mémoire collective du peuple Bassa (Centre \& Littoral) [^10][^11] |
| **Base principale** | Poudre de Mbongo (épice tropicale brûlée) [^10][^12] |
| **Ingrédients clés** | Poisson ou viande, tomate, oignon, ail, piment, mélange d'épices triées [^10][^13] |
| **Caractéristique** | Sauce de couleur noire foncée (ébène), très épicée [^10][^11][^13] |
| **Accompagnement** | Tubercules, plantains, miondo [^12] |
| **Cuisson** | Épices brûlées donnent la couleur noire, cuisson mijotée [^13][^12] |


***

### **Le Met de Pistaches** (Mukon mwa Ngondo)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Plat traditionnel Sawa Sawa, partagé avec les Bassa [^14] |
| **Base principale** | Pistaches (graines de courge) écrasées [^14][^15] |
| **Ingrédients clés** | Œufs, huile d'arachide, écrevisses, poisson/viande fumés, piment, sel [^14][^15] |
| **Caractéristique** | Pâte homogène emballée dans feuilles de bananier, gâteau pudding [^14][^16] |
| **Accompagnement** | Miondo, vin de palme (traditionnel) [^14] |
| **Cuisson** | Feu de bois, 2 heures à la vapeur dans marmites [^14] |
| **Symbolique** | Symbolisait la naissance de Jésus, mangé le 25 décembre [^14] |


***

### **Le Met d'Escargots** (Cuit à l'étouffée)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Mollusques préparés selon technique camerounaise traditionnelle [^17] |
| **Base principale** | Escargots (limançons) nettoyés et débarrassés de glaire [^17] |
| **Ingrédients clés** | Tomates, oignons, ail, piment, feuilles d'odjom, basilic, poivre blanc, poireau [^18] |
| **Caractéristique** | Cuisson à l'étouffée, mijoté 15 min à feu doux [^18][^17] |
| **Accompagnement** | Riz, plantains, miondo |
| **Préparation** | Escargots lavés 3 fois, bouillis 1/4h avec bouquet garni [^17] |


***

### **Le Met de Maïs** (Mbaafon)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Mét traditionnel à base de maïs des peuples du Littoral |
| **Base principale** | Maïs frais |
| **Ingrédients clés** | Maïs, arachides, huile de palme, piment |
| **Caractéristique** | Gâteau de maïs frais,版本 sucré ou salé |
| **Accompagnement** | Feuilles de banane pour cuisson |
| **Cuisson** | Gâteau envelopdé dans feuilles, cuisson vapeur |

*Note : Information limitée trouvée sur "mbaafon" spécifique – ce plat pourrait aussi être appelé "Ekomba" ou "gâteau de maïs arachide" [^19]*

***

### **Le Nsugi** (Sauce au Noir de Palme / Nsugui)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Sauce traditionnelle cajmerounaise, partagée par Bassa et Beti [^20][^21] |
| **Base principale** | Jus de noix de palme (noix du village) [^20][^21] |
| **Ingrédients clés** | Poisson fumé/viande fumée, ail, piment, oignon, thym, laurier, gombo, feuille d'odjom [^20][^21] |
| **Caractéristique** | Sauce au jus de palme onctueuse, couleur foncée [^20] |
| **Accompagnement** | Riz, miondo, plantains |
| **Cuisson** | Noix pilées, jus extrait et passé au tamis, cuisson 10-15 min puis ajout condiments [^20][^21] |


***

### **Le Mintoumba** (ou Mimtumba)

| Aspect | Description |
| :-- | :-- |
| **Origine** | Gâteau traditionnel totem des populations Bassa (Littoral) [^22][^23][^24] |
| **Base principale** | Manioc frais fermenté [^22][^23][^25] |
| **Ingrédients clés** | Huile de palme rouge, feuilles de marantacées (ou bananier) [^22][^23] |
| **Caractéristique** | "**Caviar des Bassa**", gâteau de manioc cuit à la vapeur [^23][^24] |
| **Utilisation** | Accompaniment à sauce OU snack consommé seul [^13][^23] |
| **Cuisson** | Vapeur, rouleÉ-en feuilles de marantacées, cuisson traditionnelle [^22][^23] |
